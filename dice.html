온라인 주사위 굴리기

6면 정육면체 주사위가 실제로 굴러가는 듯한 모션을 재생한 뒤, 멈춘 주사위의 실제 눈금이 결과로 표시됩니다.

버튼을 누르면 각 주사위가 튀어 오르며 여러 축으로 회전하고 마지막에는 결과 숫자가 위에 크게 표시됩니다.

굴리기 전입니다

사용 방법

  1. 참가 인원을 선택합니다.
  2. 주사위 굴리기 버튼을 누릅니다.
  3. 각 주사위의 움직임이 멈출 때까지 기다립니다.
  4. 위쪽 결과 숫자와 주사위 눈금을 확인합니다.

이런 때 유용해요

친구들과 게임 순서를 정하거나, 보드게임의 무작위 결정을 대신하거나, 간단한 선후공을 정할 때 활용할 수 있습니다.

결과 생성 방식

브라우저의 JavaScript Math.random()을 이용해 1부터 6 사이 값을 만들고 그 값에 맞춰 주사위의 최종 방향을 정합니다. 일반적인 게임·일상용이며 보안 목적의 난수 생성기는 아닙니다.
