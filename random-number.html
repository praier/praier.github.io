랜덤 뽑기

숫자 범위를 정하거나 직접 이름·번호·항목을 입력해 여러 개의 제비 중 하나를 직접 골라 결과를 확인해보세요.

이름, 숫자, 메뉴, 경품 등 무엇이든 한 줄에 하나씩 입력할 수 있습니다.

제비가 섞여 나타나면 원하는 막대 하나를 직접 클릭하세요. 선택한 제비가 올라오며 내용이 공개됩니다.

-

제비 하나를 골라보세요.

숫자뿐 아니라 이름도 뽑을 수 있어요

기본 모드에서는 최소값과 최대값 사이의 숫자를 제비에 넣습니다. 직접 입력 모드에서는 사람 이름, 번호, 메뉴, 경품처럼 원하는 내용을 한 줄씩 입력해 제비를 만들 수 있습니다.

재미있게 활용하는 방법

순서 정하기, 작은 이벤트의 추첨, 게임 플레이어 선정, 메뉴 선택, 간단한 경품 추첨 등 여러 상황에 사용할 수 있습니다.

결과 생성 방식

브라우저에서 JavaScript 난수 기능을 이용해 제비 내용을 무작위로 배치하고, 사용자가 하나를 고르면 해당 항목을 결과로 공개합니다.
