입력 정보는 어떻게 처리하나요?

현재 제공되는 랜덤 도구의 처리 방식을 안내합니다. 기준일: 2026년 9월 15일

1. 사용자가 입력하는 정보

제비 후보, 참가자 이름, 숫자 범위와 팀 수는 현재 열린 화면에서 결과를 계산하는 데 사용됩니다. 이 도구의 코드는 해당 값을 서버로 전송하거나 파일로 보관하지 않습니다. 이름 대신 별칭이나 번호를 사용해도 됩니다.

2. 보관과 삭제

입력값과 결과는 페이지의 메모리에서 처리하며, 도구는 localStorage나 쿠키에 이를 저장하지 않습니다. 새로고침하거나 페이지를 떠나면 현재 화면의 결과는 초기화됩니다. 별도의 결과 복구 기능은 없습니다. 브라우저 자체의 자동 완성이나 뒤로 가기 복원은 브라우저 설정에 따라 달라질 수 있습니다.

3. 광고·분석과 호스팅

현재 버전에는 Google AdSense 광고 코드나 별도의 방문 분석 스크립트가 설치되어 있지 않습니다. 따라서 이 도구 자체에서 광고용 쿠키를 생성하지 않습니다. 사이트 접속, 로그인 및 호스팅 운영 과정의 데이터 처리는 이용 중인 플랫폼의 정책을 따릅니다.

4. 외부 사이트

프로젝트 링크를 누르면 GitHub로 이동합니다. 그곳에서 작성하는 글과 계정 정보에는 GitHub의 정책이 적용됩니다. 공개 게시글에는 연락처, 민감한 정보 또는 실제 참가자 명단을 적지 마세요.

5. 변경과 문의

광고나 외부 분석 기능이 추가되어 정보 처리 방식이 달라지는 경우 그 기능에 맞게 이 안내를 갱신합니다. 오류나 안내 내용에 관한 의견은 문의 안내에서 프로젝트 연결 방법을 확인해주세요.
